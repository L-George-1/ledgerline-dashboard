# Ledgerline marketing dashboard

Open the app: https://l-george-1.github.io/ledgerline-dashboard/

It runs entirely in your browser. To try it, download `sample-data.zip`, unzip it, and upload the eight CSV files (fictional data). To use the AI features, enter your own Anthropic API key; it stays in your browser and is sent only to Anthropic.

To run it offline, download this repository and double-click `index.html`.
